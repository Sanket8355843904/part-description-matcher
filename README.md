# Part Description Matcher

A Streamlit application to compare two Excel sheets containing part descriptions using fuzzy matching.

## Features

- Upload two Excel files
- Select description columns
- Automatic fuzzy matching
- Match percentage
- Top match suggestion
- Download results as Excel

## Libraries Used

- Streamlit
- Pandas
- RapidFuzz
- OpenPyXL

## Deployment

Deploy directly on Streamlit Cloud.
